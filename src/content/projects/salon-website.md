## Overview

A responsive multi-page business website deployed on Vercel. Designed with a mobile-first layout, interactive booking system, and curated styling portfolio for a premium hair salon brand.

## Key Technical Details

- **Framework**: Next.js App Router with React and TypeScript
- **Booking**: Interactive calendar with real-time slot availability via Prisma + SQLite
- **Design**: Custom micro-interactions, dark/copper luxury theme with Tailwind CSS
- **Content**: Service listings with duration/pricing and a lookbook gallery
