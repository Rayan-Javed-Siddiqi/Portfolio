## Overview

BlueSpace is a Facebook-inspired social network desktop client built from scratch using SFML. Implements user registration/login, post creation, a scrollable home feed, and persistent user data stored in flat files.

## Key Technical Details

- **Architecture**: Object-oriented design with separate Page, User, Post, and LoginWindow modules
- **UI**: Custom SFML-rendered windows, fonts, and interactive components
- **Data persistence**: User credentials and posts saved to local text files
- **Platform**: Windows desktop app built with Visual Studio and SFML 2.x
