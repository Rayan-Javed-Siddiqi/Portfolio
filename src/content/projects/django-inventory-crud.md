## Overview

A production-style Django web app for managing product inventory. Includes user signup/login, full CRUD operations via server-rendered templates, and a documented REST API layer for programmatic access.

## Key Technical Details

- **Auth**: Session-based login with protected inventory routes
- **CRUD**: Add, view, edit, and delete products through Django templates
- **REST API**: DRF ModelViewSet with Token Authentication — all endpoints tested via curl
- **Config**: `.env` secret management, clean project structure, SQLite out of the box
