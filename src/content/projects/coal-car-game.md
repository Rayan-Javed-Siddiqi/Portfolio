## Overview

A side-scrolling car game developed as a COAL (Computer Organization & Assembly Language) course project. Implements core game mechanics including movement physics, obstacle collision, score tracking, and frame-by-frame game-loop management.

## Key Technical Details

- **Game loop**: Fixed-timestep update and render cycle
- **Physics**: Movement, gravity, and collision response
- **Scoring**: Dynamic score updates based on player performance
- **Architecture**: Entity-based design with modular game state management
